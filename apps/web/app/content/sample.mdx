## Why MDX

- **Markdown** for prose
- **JSX** when you need logic
- **Components** when you need structure

You can interpolate values from frontmatter or any ESM export:

```ts
export const sum = (a: number, b: number) => a + b
console.log(sum(2, 3)) // 5
```
