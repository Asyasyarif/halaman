## Prerequisites

- **Node.js** 22 or later
- **pnpm** 9 or later
- **Git** (only for the GitHub sync feature)

## Install

<CodeBlock language="bash">
{`git clone https://github.com/Asyasyarif/halaman.git
cd halaman
pnpm install
cp .env.example .env
pnpm dev`}
</CodeBlock>

The dev server boots on `http://localhost:3333`.

## Create your first page

<Steps>
  <Step title="Open the content directory">
    All docs live in `apps/web/app/content/docs/`.
  </Step>
  <Step title="Add a new .mdx file">
    Create `apps/web/app/content/docs/hello.mdx` with some frontmatter and prose.
  </Step>
  <Step title="Save and refresh">
    Vite HMR reloads the route instantly at `/docs/hello`.
  </Step>
</Steps>

## Project structure

```
apps/web/app/
  content/docs/       # ← MDX lives here
  pages/docs/         # ← auto-routes
  components/docs/    # ← Callout, Card, Steps, Tabs, etc.
  composables/        # ← useDocsNav(), useDocsPage()
```

<Callout variant="success" title="That's it">
  You now have a working docs site. Add a new `.mdx` file under
  `app/content/docs/` and it becomes a route — no router config, no build step.
</Callout>
